# videopeliclippisofta
Käyttäjä pystyy luomaan tunnuksen ja kirjautumaan sisään sovellukseen.
Käyttäjä pystyy lisäämään sovellukseen pelaamiaan klippejä (otsikko, peli, linkki videoon ja kuvaus). Lisäksi käyttäjä pystyy muokkaamaan ja poistamaan lisäämiään klippejä.
Käyttäjä näkee sovellukseen lisätyt klipit. Käyttäjä näkee sekä itse lisäämänsä että muiden käyttäjien lisäämät klipit.
Käyttäjä pystyy etsimään klippejä hakusanalla (otsikko, pelin nimi tai kuvaus) tai luokittelun perusteella. Käyttäjä pystyy hakemaan sekä itse lisäämiään että muiden käyttäjien lisäämiä klippejä.
Sovelluksessa on käyttäjäsivut, jotka näyttävät jokaisesta käyttäjästä tilastoja (esim. lisättyjen klippien ja saatujen kommenttien määrä) sekä käyttäjän lisäämät klipit.
Klipeille on valittavissa useampia luokitteluja (esim. pelin genre, klipin tyyppi ja alusta). Valittavissa olevat luokat ja vaihtoehdot on määritelty tietokannassa. Käyttäjä voi valita jokaisen luokittelun kohdalla yhden tai useamman vaihtoehdon.
Sovelluksessa on klipin lisäksi toissijainen tietokohde, kommentti, joka täydentää klippiä. Käyttäjä pystyy lisäämään kommentteja sekä omiin että muiden käyttäjien klippeihin.
